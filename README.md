# MicMute (麦克风工具)

一个简单实用的麦克风控制工具，支持快捷键切换、按住开麦以及屏幕指示器功能。

## 🌟 功能特点

* **快捷键控制**：支持“切换开麦”和“按下开麦（Push-to-Talk）”两种模式。
* **自定义按键**：可自由绑定符合自己习惯的快捷键。
* **屏幕指示器**：实时在屏幕上反馈当前音量与麦克风状态，支持位置锁定。

## 📦 下载与安装

1. 前往 [Releases](https://github.com/maolbsMd/MicMute/releases) 页面下载最新版本的压缩包。
2. 解压后运行 `micmute.exe` 即可使用（无需安装）。
